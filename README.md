# Meu Portfólio (versão inicial)

Meu primeiro site pessoal, feito para praticar HTML, CSS e JavaScript no início da minha jornada.

🔗 **Ver online:** https://victormoraiss.github.io/Meu-Portfolio/

## O que tem
- Navegação por seções: Início, Sobre, Projetos e Contato
- Cards de projetos e formulário de contato que abre o WhatsApp

## Tecnologias
HTML, CSS e JavaScript.

## O que aprendi
- Montar uma página com várias seções e menu
- Estilizar com CSS (cartões, fundo com gradiente, botões)
- Ligar um formulário a um link de WhatsApp com JavaScript

## O que eu faria diferente hoje

- Usar variáveis de cor no CSS e cuidar do contraste dos links
- Escrever o README desde o primeiro commit
